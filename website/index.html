What Works Today

Fireflies Overlay

Dragonflies Overlay

Translucent sakura cherry blossom petals with 3D flip tumbling, taskbar ground resting, and 5-minute wind impulse physics.

Click-Through Transparency

Hardware-accelerated frameless transparent windows allowing full mouse interactivity to pass through to active apps.

EARLIER WORKING PROTOTYPE — NOT INCLUDED IN CURRENT NATURE RUNTIME BUILD

Ohverlay began inside a real technical office.

Before becoming an ambient nature platform, Ohverlay was created in a Saudi Arabian engineering office to coordinate multi-workstation technical workflows. An earlier version provided persistent sticky instructions, timed countdown tasks, supervisor reporting, staff acknowledgements, and local-network file handoffs without interfering with CAD and engineering software.

Why Desktop Overlays?

Traditional applications compete for focus by hiding underneath each other. Ohverlay introduces a spatial alternative.

Non-Intrusive Presence

Overlays exist in a dedicated transparent window layer above application windows, maintaining visibility without taking window focus.

Zero Workflow Interruption

Hardware input pass-through guarantees that clicks, drags, and keypresses pass directly to whatever application you are working in.

Calm Information Architecture

By restricting visual density and movement speeds, information is perceived passively rather than demanding immediate cognitive attention.

Privacy and Ethical Design

Ohverlay is designed around a strict local-first, privacy-respecting doctrine.

100% Offline & Local-First

All settings, overlay renderers, and configurations remain stored locally on your machine (`~/.ohverlay/config.json`).

Zero Telemetry Tracking

Ohverlay records zero analytics, personal data, or usage logs. No background telemetry calls are ever made.

Explicit User Consent

Optional network features or future assistant integrations require explicit user activation and approval.
