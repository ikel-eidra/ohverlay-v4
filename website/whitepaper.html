Product & Technical Doctrine Whitepaper

A technical specification on the spatial desktop overlay paradigm and local-first architecture.

1. The Spatial Desktop Overlay Paradigm

Modern operating systems treat windows as competing opaque rectangular boundaries. When an engineer, researcher, or student switches tasks, information in secondary windows is completely obscured. Ohverlay introduces a spatial transparent layer above active application windows (`Qt.WindowStaysOnTopHint | Qt.WindowTransparentForInput`) that presents passive information without stealing focus.

2. Local-First Architecture

Ohverlay enforces a strict offline-first doctrine. Renderers are packaged directly as local HTML5 Canvas elements loaded into frameless `QWebEngineView` containers. User preferences reside at `~/.ohverlay/config.json`. The platform operates with zero required cloud services or remote tracking calls.

3. Blue AI Integration Specification

Blue AI represents an optional future research lane for contextual intelligent assistance. Unlike intrusive AI sidebars, Blue AI operates strictly on-demand, reading screen context upon explicit user hotkey trigger (`Ctrl + Alt + B`) to answer questions, explain code snippets, or analyze active documentation.
