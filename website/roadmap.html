Platform Development Roadmap

A staged roadmap for restoring and expanding Ohverlay's six platform lanes.

PHASE 1 — COMPLETED BASELINE

1. Stable Desktop Nature Runtime

Clean standalone Python PySide6 QWebEngine architecture delivering 4 verified living overlays (Fireflies, Dragonflies, Dandelion Seeds, Sakura Petals) with Control Center tray interaction.

PHASE 2 — IN DEVELOPMENT

2. Technical Office Rebuild

Restoring sticky instructions, timed countdowns, supervisor acknowledgements, and local LAN file handoffs under the local-first architecture.

PHASE 3 — PLANNED

3. Overlay Package Manager & Creator Ecosystem

Open package manifest specification (`manifest.json`) allowing third-party creators to author and publish custom desktop overlays.

PHASE 4 — RESEARCH

4. Optional Blue AI Screen Integration

On-demand screen-aware assistant providing contextual support upon explicit user hotkey request.
